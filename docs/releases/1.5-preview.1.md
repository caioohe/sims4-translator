# The Sims 4 Translator 1.5-preview.1

## Português (Brasil)

Primeira pré-release do fork de confiabilidade de caioohe, derivado de voky1/sims4-translator.

**Baixe `Sims4Translator-1.5-preview.1-Windows-x64.zip` nos Assets abaixo.** Extraia o ZIP inteiro em uma pasta com permissão de escrita e abra `Sims4Translator.exe`. Não baixe “Source code” se deseja o programa pronto.

Novidades:
- APIs oficiais Gemini e Microsoft Translator, com teste de tradução nas opções.
- Proteção de variáveis, tags, escapes e ramos de gênero antes de aplicar os resultados.
- Lotes configuráveis até 100 textos para Gemini/Microsoft; DeepL limitado a 50.
- Timeouts, tentativas limitadas e tratamento de limites dos provedores implementados.
- Recuperação dos lotes concluídos e correções demonstradas de package/STBL.
- Configurações dos provedores na aba Geral; salvamento ao fechar Opções e escrita atômica.
- Número `1.5-preview.1` no título do programa.

A publicação depende dos 146 testes no Windows com Python 3.12/3.14 e do build PyInstaller. Os testes usam HTTP simulado e pacotes sintéticos. Não certificam autenticação da sua conta, qualidade semântica, todos os mods ou resultado no jogo. Google Translate continua usando HTML não oficial e pode sofrer bloqueios. A perda relatada de chave no fechamento normal não foi reproduzida no PC do usuário.

Guia incluído: `README-Windows.md`, `MICROSOFT.md` e `GEMINI_GOOGLE.md`. API keys e arquivos pessoais não estão incluídos. Licença MIT e créditos originais preservados. Pré-release para revisão; nenhum merge no upstream ou na main do fork.

## English

First preview of caioohe's reliability fork, derived from voky1/sims4-translator.

**Download `Sims4Translator-1.5-preview.1-Windows-x64.zip` from Assets below.** Extract the entire ZIP into a writable folder and run `Sims4Translator.exe`. “Source code” is not the ready-to-run application.

Changes:
- Official Gemini and Microsoft Translator APIs with translation test buttons.
- Validation of variables, tags, escapes and gender branches before applying results.
- Configurable batches of up to 100 texts for Gemini/Microsoft; DeepL capped at 50.
- Timeouts, bounded retries and provider rate-limit handling in the implemented adapters.
- Completed-batch recovery and demonstrated package/STBL fixes.
- Provider settings in General; saving when Options closes and atomic config writes.
- `1.5-preview.1` displayed in the application title.

Publication requires 146 tests on Windows/Python 3.12 and 3.14 and a successful PyInstaller build. Tests use mocked HTTP and synthetic packages. They do not certify account authentication, semantic quality, every mod variant or in-game results. Google Translate still uses unofficial HTML and can be blocked. Reported key loss on normal exit was not reproduced on the user's PC.

Included guides are currently in PT-BR: `README-Windows.md`, `MICROSOFT.md` and `GEMINI_GOOGLE.md`. No API keys or personal files are included. Original credits and MIT license are preserved. This is a pre-release for review, with no merge into upstream or the fork's main branch.
